Llama Score User Manual
  1. Download the Llama Score Dashboard (the button at the top of this page). It comes as a .zip - unzip the whole thing into a permanent folder first (e.g. your Desktop or Documents), not left inside Downloads or a still-zipped view. Everything in that folder needs to stay together and stay put, since it's where the Dashboard will also keep its recorded ledger.
  2. Run Llama Score Dashboard.exe from that folder and leave it running in the background while you play (right-click the exe → "Send to" → "Desktop (create shortcut)" if you want it easy to relaunch next time). Its Settings button controls two folders, both already defaulted for a typical install:
    • EU5 save folder - where it watches for new autosaves. Defaults to your own Documents\Paradox Interactive\Europa Universalis V\save games. Only change this if your saves live somewhere non-default (a different drive, a custom Documents location, etc).
    • Ledger data folder - where it records what it sees. Defaults to a data folder it creates right next to the .exe - this is the same folder you'll point this webpage at in the next step. Only change this if you specifically want the ledger stored somewhere else; most people never need to touch it.
  3. Play normally. EU5 autosaves periodically; the Dashboard reads each new one as it lands and builds up a running log of every war in your campaign - including wars that get cleared out of the save itself before you'd otherwise catch them as "concluded."
  4. Come back to this tab any time you want to check scores. Click "Connect campaign folder…" below (one-time per browser) and pick the data folder that appeared next to Llama Score Dashboard.exe once you ran it - after that, loading any save from a linked campaign shows its Llama Score automatically, no more picking required.
  5. Multiplayer note: there's no server and no automatic syncing between different players' computers - each person who wants to see live scores runs their own copy of the Dashboard against their own save folder. Since everyone's client is autosaving the same shared campaign, everyone ends up tracking the same wars independently.

Manual setup / troubleshooting
ⓘ ✅ Linked!

Pick the recorder's data folder — next to Llama Score Dashboard.exe if you used the Dashboard app, or directly inside llama-score-automatic-logging-machine if you ran the CLI recorder script. Don't pick its parent folder, and not one specific campaign's folder inside data/campaigns.

How are these scores calculated?
GP Score
(27 − Great Power Rank + 1) × 75, floored at 0 for rank 28+. Rank 1 (strongest) scores highest; only the top 27 ranked countries score anything.
War Score
Per finished war: reward for winning against more Enemies with fewer Allies to share credit with; penalty for losing scaled the same way. A war with no real combatant on either side (a hired condottieri contract) uses a flat ±2 instead. In PVE mode, a vassal/subject fighting alongside its own overlord on the same side doesn't count as a separate Enemy or Ally - beating "the Ottomans + 3 vassals" scores the same as beating just "the Ottomans", since it's really one fight against one empire. A vassal fighting entirely on its own (its overlord isn't in that war) still counts normally.
Llama Points / Alpaca Points
(GP Score ÷ 100) + ∑ War Score across every one of the player's scored wars this campaign - called Llama Points in PVP mode and Alpaca Points in PVE mode so the two leaderboards are never confused for one another, even though it's the exact same formula either way.
White Peace
When nothing in the data points to a winner either way, the war is scored as a flat 0 for both sides rather than guessing - shown separately below from wars that were actually decided. This also covers the case where EU5's own in-game war score only survives for one side by the time the recorder captures it (the other already reset to nothing) - a lone leftover number isn't a real two-sided comparison, so it's no longer used to guess a winner; it falls through to White Peace instead.
